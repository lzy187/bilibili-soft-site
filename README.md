# B站全站柔和显示

**[安装脚本](https://raw.githubusercontent.com/lzy187/bilibili-soft-site/main/bilibili-soft-site.user.js)** · [反馈问题](https://github.com/lzy187/bilibili-soft-site/issues) · [更新记录](./CHANGELOG.md)

觉得 B 站深色模式里的白字、表情包和封面太亮？本脚本配合哔哩哔哩 bilibili 自带深色模式，降低常见页面元素的亮度，适合希望在 OLED 等显示器上获得柔和观感的用户。

## 功能

- 将标题、简介、评论、推荐列表中的亮白文字和常见 SVG／字体图标调整为柔和灰色。
- 提供“稍柔和”“柔和”“更暗”三个文字档位，支持自定义颜色。
- 保留原本较暗的文字与饱和度较高的彩色文字，例如常见蓝色链接。
- 独立调整表情／评论内图片与封面／头像等普通图片的亮度。
- 保持视频画面亮度，不对整个页面或播放器容器施加亮度滤镜。
- 适配可访问的嵌套 Shadow DOM 评论区，处理动态插入的页面内容。
- 设置保存在脚本管理器中；不添加广告、不上传数据、不加载外部代码。

## 使用方法

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 点击上方 **安装脚本**，在 Tampermonkey 弹出的页面中安装。也可以打开仓库中的 [脚本文件](./bilibili-soft-site.user.js)，点击 GitHub 文件页面的 **Raw**。
   - 如果只显示代码：复制全部代码，在 Tampermonkey 中添加新脚本，全选替换默认内容后保存。
3. 打开 B 站并启用网站自带深色模式；本脚本不负责开启深色模式。
4. 刷新页面，点击浏览器工具栏的 Tampermonkey 图标。
5. 在脚本菜单中选择文字档位，或设置图片亮度。

默认文字颜色为 `#a8adb4`，表情／评论内图片亮度为 75%，封面／头像等普通图片亮度为 85%。

图片亮度可输入 40～100，设为 100 即关闭该类图片的调暗。图片使用整体亮度处理，因此彩色部分也会一起变暗。评论内的普通图片也可能归入“表情／评论内图片”一组。

切回浅色主题时，请通过菜单关闭本脚本。调整参数无需刷新视频。

从上述链接安装后，脚本管理器可通过 GitHub 检查更新，具体检查时间取决于脚本管理器的设置。

## 适用范围与已知限制

- 主要针对 B 站自带深色模式；不保证与其他深色主题扩展、滤镜或同类脚本兼容。
- 不处理视频／Canvas 画面、封闭 Shadow DOM 和跨域 iframe；部分背景图片、特殊图标及特殊颜色格式可能无法覆盖。
- 并非 B 站所有子站、布局和浏览器均已验证；网站改版可能需要适配。
- 已进行 Edge 内核浏览器的本地功能测试，包括文字过渡、动态节点、嵌套评论、图片滤镜、恢复开关。实际 B 站使用已有用户反馈，其他环境欢迎反馈。
- 如曾安装“B站评论柔和文字”或旧版“B站全站柔和显示”，请先停用旧版，避免同时运行。
